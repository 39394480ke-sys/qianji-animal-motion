# 39-Point VGT Motion Pipeline Design

## Goal

Build one reproducible cat acceptance pipeline:

```text
cat video + Hunyuan3D-derived initial mesh
  -> 39-point image trajectory
  -> mesh-constrained body-relative 2.5D landmarks
  -> 39-point 3D motion
  -> six-role VGT control targets
  -> 12-site, 30-rod VGT motion sequence
  -> 30 FPS structure previews and validation report
```

The pipeline extends the existing six-point implementation without changing
its schemas or behavior.

## Scope

The delivered model sequence is the sparse QianJi VGT structure. Full
deformation of the 2,154-vertex triangle mesh, monocular mesh reconstruction,
MuJoCo dynamics, and non-quadruped generalization are excluded.

All 3D landmark values are body-relative 2.5D retargeting outputs. Image
longitudinal and vertical displacement are observed; lateral placement comes
from the neutral mesh-derived VGT frame and remains fixed. No output may claim
observed metric camera depth or preserved world translation.

## Source Evidence

The real acceptance inputs are:

- 272-frame, 1246x720, 30 FPS processed cat video;
- DeepLabCut SuperAnimal-Quadruped H5 with 272 rows, one individual,
  39 bodyparts, and `x`, `y`, `likelihood` coordinates;
- Assimp GLB containing 2,154 vertices and 4,304 faces, described by the user
  as generated by Hunyuan3D from a video frame;
- corrected six-point trajectory whose confirmed identity reference is frame
  152;
- QianJi as a read-only downstream morphology and reachability dependency.

The input manifest records user-provided Hunyuan3D provenance separately from
the verifiable FBX-to-GLB conversion metadata. It does not invent an unknown
Hunyuan generation image path or generation parameter.

## Architecture

### Observation layer

`keypoint_trajectory_2d_39.json` contains every H5 bodypart in every frame.
Points below the confidence threshold, outside the image, non-finite, or
rejected as a discontinuity are retained as named roles with `valid: false`
and null coordinates. No interpolation, smoothing, or role deletion occurs.

Front and rear left/right leg chains use the existing bidirectional identity
resolver with the confirmed frame-152 anchor. A swap applies to the complete
thigh-knee-paw chain rather than only the paw. Other paired head and body
landmarks retain the source model identity and are reported as such.

The two-dimensional preview draws valid points and anatomical edges over the
source video. The quality report provides per-role confidence statistics,
invalid frames, flag counts, and leg identity corrections.

### Neutral 39-landmark layer

The reference two-dimensional body frame is defined by the corrected
`spine_rear` and `spine_front` points at frame 152. Every raw landmark,
including a low-confidence reference observation, receives a deterministic
longitudinal and vertical coordinate in that frame.

The neutral three-dimensional frame is derived from the QianJi robot and its
quadruped rig:

- forward: rear-spine site to front-spine site;
- up: global +Z orthogonalized against forward;
- lateral: `cross(forward, up)`;
- scale: neutral spine-site distance;
- left/right offset: sign and half-width derived from left/right rig sites.

Each neutral landmark is placed from its reference body coordinates plus a
fixed lateral offset based on its role name. Centerline roles have zero
lateral offset. Cat-inapplicable SuperAnimal roles such as antler landmarks
remain present, are marked `anatomy_applicable: false`, and always emit
confidence zero rather than being silently removed.

`neutral_landmarks_39.json` records the neutral XYZ, side, applicability,
reference confidence, construction method, basis, and source hashes.

### 39-point 2.5D motion

Each frame uses the corrected six-point spine to define a body-relative 2D
frame. Valid 39-point observations are normalized by that frame's torso
length, compared with their reference coordinates, and transferred along the
neutral VGT forward and up axes:

```text
p3_k(t) = neutral_k
        + motion_scale * torso_length_3d
        * (delta_long_k(t) * forward_3d
           + delta_vertical_k(t) * up_3d)
```

Lateral displacement is always zero. Invalid observations emit the role's
neutral XYZ with confidence zero and a substitution record. The output
contains exactly 272 frames and all 39 role names in every frame.

### VGT control layer

Thirty-nine observation roles do not map one-to-one onto 12 structural sites.
`vgt_control_map.json` explicitly separates them:

- `spine_front` <- `back_base`, fallback `neck_base`;
- `spine_rear` <- `back_end`, fallback `tail_base`;
- four foot roles <- their corresponding paw observations.

For each control role, the observation landmark's displacement from its own
neutral position is added to the mapped VGT site's neutral position. Thus the
reference frame exactly matches the rig even when an anatomical landmark is
not located at the structural site.

Invalid primary observations may use only an explicitly named same-frame
fallback from the control map. When no valid source exists, the control target
is the neutral site with confidence zero. Every fallback and substitution is
reported; there is no temporal interpolation.

Two rig candidates are evaluated:

- QianJi `quadruped_bbox`;
- motion-informed distinct-site assignment minimizing reference landmark to
  site distance.

### Reachability study

The study compares:

- motion scales `0.05`, `0.10`, and `0.15`;
- zero and 10 percent permitted contraction ranges;
- bbox and motion-informed rig candidates;
- base and QianJi fixed-topology morphology-optimized robots.

QianJi remains read-only. Contraction candidates are versioned robot copies in
the experiment output, and morphology optimization writes only to the
experiment directory.

Every candidate retains its raw desired control trajectory and QianJi's
constraint-projected control trajectory as different files. The aggregate
`reachability_report.json` records parameters, source paths, hashes, status
counts, maximum control error, rod violations, clipping, and eligibility.

An eligible candidate has:

- 272 frames;
- zero unreachable frames;
- maximum control-point error no greater than 0.05 m;
- finite VGT positions with shape `(272, 12, 3)`;
- all 30 rod endpoint references valid.

The selected candidate is the highest eligible motion scale, then the highest
feasible fraction, then the lowest maximum control error. Strict physical
feasibility is reported but is not a dynamics claim.

### VGT sequence and rendering

The selected QianJi site-target NPZ is republished as `vgt_motion.npz` with
`site_names`, `times`, and `positions`. `vgt_motion_manifest.json` records:

- schema and scientific limitations;
- selected candidate and all source hashes;
- frame count, FPS, time range, and exact array shapes;
- all site names;
- all 30 rods and endpoint names;
- robot and rig association;
- distinct desired and projected keypoint paths.

The renderer uses the fixed robot connectivity and selected site positions to
draw nodes and rods in top, side, front, and isometric views. It produces
non-empty static views and a 1246x720, 30 FPS, 272-frame MP4 without using the
triangle mesh as a deforming surface.

## Failure and publication policy

Every source is hashed before use and rechecked before owned artifacts are
published. Output roots must not already exist. Each stage writes a complete
staging directory and refuses to overwrite versioned results.

JSON serialization rejects NaN and infinity. NPZ validation rejects non-finite
values, shape mismatches, duplicate or missing sites, non-monotonic time, and
rod endpoint errors. Video validation uses FFprobe and requires 30 FPS and 272
frames.

## Test strategy

Unit tests use literal synthetic 39-role data, a 12-site/30-rod robot, and
controlled images to prove:

- all roles and frames are preserved;
- low-confidence points remain explicit invalid entries;
- chain identity swaps apply to thigh, knee, and paw;
- no interpolation occurs;
- neutral left/right landmarks have different lateral coordinates;
- reference landmarks map to neutral XYZ;
- invalid 3D points use neutral XYZ with confidence zero;
- control targets are site-neutral at the reference frame;
- desired and projected trajectories have different provenance;
- VGT arrays and manifests enforce `(272, 12, 3)` and 30 valid rods;
- rendered video properties meet the contract;
- source mutation and overwrite attempts fail without partial outputs.

The existing six-point test suite must remain green. The final real-data audit
validates every named deliverable and acceptance criterion before completion.
